Servicio principal

Diseño Web (rápido, claro y optimizado)

Creamos webs que no solo se ven bien: están pensadas para guiar al usuario, generar confianza y convertir visitas en contactos, reservas o ventas.

Qué incluye

  • • Arquitectura de secciones (estructura que vende)
  • • Diseño UI + UX (responsive)
  • • Copy base orientado a conversión (si no tienes texto)
  • • Performance (peso, imágenes, carga)
  • • SEO técnico base (titles, h-tags, schema, sitemap)
  • • Formularios / WhatsApp / CTA
  • • Analítica (GA4 o alternativa) + eventos básicos

Entregables

  • • Web publicada + checklist de calidad
  • • Versión móvil perfecta
  • • Imágenes optimizadas + alt text
  • • Setup de indexación (Search Console)
  • • Mini guía para mantener / actualizar

Tiempo típico: 1–3 semanas (según alcance).

Servicio

Branding & Identidad Visual (coherente y usable)

Logo bonito sin sistema = marca frágil. Creamos una identidad que se vea bien en web, redes, tarjetas, menús, packaging y donde lo necesites.

Qué incluye

Entregables

  • • Plantillas base (opcional)

Tiempo típico: 1–3 semanas.

Servicio

SEO & Contenido (para que te encuentren)

No existe “SEO mágico”. Existe estructura + intención + contenido. Te dejamos una base sólida y páginas que posicionan.

Qué incluye

  • • Research de keywords (Barcelona + sector)
  • • Arquitectura SEO (páginas y categorías)
  • • Titles, descriptions, H1-H3
  • • Schema (LocalBusiness, FAQ, etc.)
  • • Interlinking (links internos que empujan)
  • • Sitemap + robots + indexación

Entregables

  • • Plan de páginas SEO (por intención)
  • • Optimización on-page
  • • 1–3 páginas SEO listas (según pack)
  • • Setup Search Console (si aplica)

Tiempo típico: 1–2 semanas para base + primeras páginas.

La publicidad funciona cuando hay base: oferta clara, landing que convierte y creatividades buenas. Si no, solo quemas dinero. Aquí se hace bien o no se hace.

Requisitos

  • • Web o landing decente
  • • Creatividades mínimas (o las hacemos)

Tiempo típico: setup 3–7 días + optimización mensual.

Hablemos

Nota honesta: si no necesitas un paquete, no te lo vendo. Te digo cuál es el mínimo que te conviene para avanzar.

Lo que NO hacemos (porque no sirve)

❌ Logos rápidos sin sistema

Un logo sin reglas no te da consistencia en web y redes.

❌ Webs lentas y sin SEO base

Si tarda, la gente se va. Y si no indexa, no existes.

❌ Prometer “#1 en Google en 7 días”

Eso es mentira. SEO es estructura y consistencia.

❌ Publicar por publicar

Redes sin estrategia es ruido. Y el ruido no vende.

❌ “Diseño bonito” sin objetivo

La estética sin intención solo decora, no convierte.

❌ Cambios infinitos sin control

Se trabaja con revisiones y criterio. Si no, nunca se entrega.

Preguntas frecuentes

¿Trabajáis solo en Barcelona?

Estamos en Barcelona, pero podemos trabajar remoto. Si el proyecto requiere sesión de foto/vídeo, coordinamos según ubicación.

¿Ofrecéis pago por fases?

Sí. Normalmente 50% al inicio y 50% a la entrega. En proyectos grandes, por hitos.

¿Qué necesitáis para empezar?

Objetivo + qué vendes + referencias. Si no tienes textos o fotos, también lo solucionamos.

¿Incluye mantenimiento?

Podemos incluirlo como extra mensual: cambios, backups y mejoras continuas.

¿Hacéis proyectos solo de un servicio?

Sí. Puedes contratar solo web, solo branding o solo foto/vídeo. Aun así, te diremos si falta algo crítico.

¿Listo para mejorar tu imagen?

Cuéntanos tu negocio y te diremos el camino más directo.
